# 🛍️ QuiCart – Modern Full Stack E-Commerce Platform

> **QuiCart** is a modern, responsive full-stack e-commerce platform built using **Nuxt 4**, **Laravel 12**, and **MySQL**. It provides a seamless online shopping experience with secure authentication, product management, shopping cart, wishlist, checkout, and an admin dashboard.

# 📖 About the Project

QuiCart is a portfolio-grade full-stack e-commerce application developed to demonstrate modern web development practices using Nuxt.js and Laravel.

The application follows a decoupled architecture where the frontend communicates with the backend through REST APIs, making it scalable, maintainable, and production-ready.

This project is being actively developed with new features added regularly.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/SuhanaParvints/QuiCart-ecommerce.git
```

---

## Frontend Setup

```bash
cd QuiCart
npm install
npm run dev
```

Frontend:

```
http://localhost:3000
```

---

## Backend Setup

```bash
cd backend

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```

Backend:

```
http://127.0.0.1:8000
```
