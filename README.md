# quicart-ecommerce
QuiCart – A full-stack e-commerce platform built with Nuxt.js and Laravel, featuring secure authentication, product management, shopping cart functionality, and a responsive user interface.

## Features

* User authentication
* Product catalog management
* Product search and filtering
* Shopping cart functionality
* Responsive design
* RESTful API with Laravel
* Fast and modern frontend with Nuxt.js

## Technologies Used

### Frontend

* Nuxt.js
* Vue.js
* HTML5
* CSS3
* JavaScript

### Backend

* Laravel
* PHP
* SQLite
* REST API

## Getting Started

### Prerequisites

* Node.js
* PHP
* Composer

### Installation

#### Frontend

```bash
cd frontend
npm install
npm run dev
```

#### Backend

```bash
cd backend
composer install
php artisan migrate
php artisan serve
```
